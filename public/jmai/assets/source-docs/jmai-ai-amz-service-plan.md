# 九米AI × Amazon SP-API 服务方案

版本：v0.1  
日期：2026-07-16  
适用对象：九米内部产品、技术、运营、SPN 服务交付团队

## 1. 方案摘要

九米已经具备出海服务基础能力，包括关务、汇率、税务、物流、海外仓、Google 流量等服务。成为 Amazon SPN 服务商后，九米可以进一步通过 Amazon Selling Partner API（SP-API）、Amazon Ads API 和相关数据能力，将服务从“人工顾问交付”升级为“数据驱动 + AI 自动化 + 服务闭环”的出海经营平台。

九米AI 的核心定位建议为：

> 面向 Amazon 卖家的出海经营智能中台，通过 Amazon 店铺数据、广告数据、关汇税数据、物流履约数据和 Google 流量数据，帮助卖家完成增长诊断、利润核算、库存补货、合规风控和服务交付自动化。

不是单纯做 ERP，也不是只做 API 工具，而是围绕九米已有服务优势，打造“Amazon 经营数据 + 跨境服务能力 + AI 决策建议”的复合型服务产品。

## 2. Amazon 接口能力基础

### 2.1 SP-API

Amazon Selling Partner API 是面向卖家和供应商的 REST API，可程序化访问订单、货件、付款、库存、商品、报表等数据。九米可围绕以下 API 能力建设服务：

| 能力域 | 可用 API/模块 | 九米可开发服务 |
| --- | --- | --- |
| 店铺授权 | OAuth、LWA、Tokens API | 多店铺授权、客户接入、权限管理 |
| 订单 | Orders API、Notifications API | 订单同步、异常订单、国家/渠道销售分析 |
| 商品 | Catalog Items API、Listings Items API、Listings Restrictions API | Listing 体检、上架合规、类目限制检测 |
| 库存 | FBA Inventory API、Supply Sources API | 库存监控、断货预警、多仓库存分析 |
| FBA 入仓 | Fulfillment Inbound API、Amazon Warehousing and Distribution API | 头程计划、入仓进度、备货协同 |
| 配送 | Fulfillment Outbound API、Shipping API、Merchant Fulfillment API | 履约管理、物流异常、运费方案 |
| 财务 | Finances API、Transfers API、Product Fees API | 利润核算、费用拆解、回款对账 |
| 报表 | Reports API、Data Kiosk API | 经营报表、批量数据分析、BI 数据底座 |
| 发票税务 | Invoices API、Shipment Invoicing API、VAT Calculation Service 相关能力 | 税务准备、发票数据、VAT/GST 辅助核算 |
| 买家互动 | Messaging API、Solicitations API | 售后消息、索评流程、服务 SLA |
| 内容 | A+ Content API | A+ 页面管理、品牌内容优化 |

### 2.2 Amazon Ads API

Amazon Ads API 可用于程序化管理广告资源并获取广告表现数据。九米可以将其与 Google Ads、GA4、落地页和 Amazon 销售数据结合，形成“站外流量到站内转化”的增长分析闭环。

可开发能力包括：

- 广告账户授权和广告数据同步
- Campaign、Ad Group、Keyword、Target、ASIN 维度报表
- ACOS、TACOS、CVR、CTR、CPC、ROAS 分析
- 广告预算异常、关键词浪费、广告吞噬利润预警
- Amazon Ads 与 Google Ads 的跨渠道归因分析

### 2.3 Data Kiosk

Data Kiosk 是 SP-API 中基于 GraphQL 的动态报表能力，可用于访问批量经营数据。九米可以用它建设经营数据仓库，减少单个报表接口拼接成本。

适合场景：

- 销售与流量分析
- SKU/ASIN 维度经营分析
- 多站点批量报表
- AI 经营诊断的数据输入
- 客户月报自动生成

## 3. 九米AI 的核心服务场景

### 3.1 Amazon 经营驾驶舱

目标：给卖家和九米顾问一个统一的经营视图。

核心功能：

- 多店铺、多站点、多币种看板
- 销售额、订单量、退款率、客单价、转化率
- SKU/ASIN 维度销售排行
- 广告花费、ACOS、TACOS、自然销售占比
- FBA 库存、可售天数、断货风险
- 财务回款、平台费用、预计利润

九米AI 输出：

- 今日经营摘要
- 异常波动说明
- 重点 SKU 机会提示
- 风险事项自动生成服务工单

示例：

> 德国站 ASIN B0XXXX 近 7 日销量上涨 38%，但 FBA 可售库存仅剩 11 天。若维持当前广告预算，预计 8 月 2 日断货。建议本周内安排补货 850 件，并同步评估空运方案。

### 3.2 真实利润核算

目标：解决卖家“销售额高但不知道是否赚钱”的问题。

数据来源：

- Amazon 订单、费用、回款、退款、FBA 费用
- Product Fees API 的预估费用
- 九米关务数据
- 头程物流成本
- 汇率
- VAT/GST/关税规则
- Amazon Ads 和 Google Ads 花费

核心功能：

- SKU 级真实毛利
- 国家/站点利润
- 平台费用拆解
- 广告后利润
- 关税/VAT 影响测算
- 汇率波动影响
- 利润红线预警

九米AI 输出：

- 哪些 SKU 看似热销但实际亏损
- 哪些国家站点利润更优
- 广告预算是否应该调整
- 价格是否低于含税含广告成本线

### 3.3 关汇税智能助手

目标：把九米已有的关务、汇率、税务服务产品化。

核心功能：

- 商品 HS Code 辅助匹配
- 目的国关税测算
- VAT/GST 应税销售额整理
- 月度税务报表辅助生成
- 发票、回款、平台费用匹配
- 税务异常风险提示

九米AI 输出：

- 税负变化解释
- 高风险商品提醒
- VAT 注册和申报节奏建议
- 清关资料缺失检查

边界说明：

AI 只能做辅助分析和资料整理，最终税务判断和申报建议应由九米专业顾问或合作税务机构确认。

### 3.4 FBA 补货与头程协同

目标：把 Amazon 库存、FBA 入仓和九米头程服务打通。

核心功能：

- 可售库存和在途库存同步
- 销量预测
- 断货日期预测
- 滞销库存识别
- 补货量建议
- FBA 入仓计划跟踪
- 头程物流方案推荐
- 清关、预约、入仓状态跟踪

九米AI 输出：

- 补货建议
- 发货方式建议：海运、空运、快递、海外仓中转
- 因清关周期导致的断货风险提醒
- 慢动销库存处置建议

### 3.5 Listing 体检与增长优化

目标：帮助卖家发现 Listing 内容、类目、合规和转化问题。

核心功能：

- 标题、五点、描述、图片、A+ 页面完整性检查
- 类目限制和销售限制检测
- 变体结构检查
- 关键词覆盖分析
- 转化率异常识别
- 竞品价格和 Buy Box 状态监测

九米AI 输出：

- Listing 评分
- 优先修改建议
- 合规风险说明
- 内容优化草案
- A+ 页面更新建议

### 3.6 Amazon Ads + Google 流量联动

目标：形成九米差异化增长服务。

九米可将 Amazon Ads API 与 Google 侧流量数据结合，分析站外引流是否真正提升 Amazon 站内表现。

核心功能：

- Google Ads 花费、点击、落地页转化
- Amazon Ads 花费、点击、转化、销售
- Amazon 自然销售变化
- 品牌词搜索变化
- 站外活动期间 ASIN 销售拉升
- 跨渠道 ROI 分析

九米AI 输出：

- Google 引流是否值得继续
- 哪些 ASIN 适合做站外投放
- 哪些关键词应从 Google 引到 Amazon
- 哪些 Amazon 广告预算应转到 Google 或反向调整

### 3.7 客户月报自动生成

目标：提升 SPN 服务交付效率。

核心功能：

- 自动抓取 Amazon、广告、库存、财务、关税、物流数据
- 按客户生成月度经营报告
- 自动生成顾问点评
- 自动列出下月行动计划
- 支持导出 PDF、PPT、在线报告

报告结构建议：

1. 本月经营概览
2. 销售与利润表现
3. 广告与流量表现
4. 库存与履约风险
5. 关汇税与财务风险
6. 重点 SKU 分析
7. 九米AI 建议
8. 下月服务计划

### 3.8 SPN 服务商交付工作台

目标：让九米内部团队用同一个系统服务客户。

核心功能：

- 客户档案
- 店铺授权状态
- 服务合同和服务包
- 顾问任务
- 风险工单
- 客户健康分
- 服务进度
- 月报和会议纪要

九米AI 输出：

- 每个客户的本周重点事项
- 哪些客户可能流失
- 哪些客户适合升级服务
- 哪些异常需要顾问介入

## 5. MVP 建议

### 5.1 MVP 目标

用 8-12 周完成可演示、可试点的版本，服务 3-5 个种子客户。

MVP 不追求覆盖所有 Amazon API，而是先打通最能体现九米价值的闭环：

> 店铺授权 → 数据同步 → 利润核算 → 库存预警 → AI 经营建议 → 顾问月报

### 5.2 MVP 功能范围

P0 必做：

- Amazon 店铺 OAuth 授权
- Orders API 数据同步
- Reports/Data Kiosk 基础经营数据同步
- FBA Inventory 数据同步
- Finances API 基础费用同步
- Amazon Ads 基础报表同步
- SKU/ASIN 利润看板
- 库存断货预警
- 客户经营月报自动生成

P1 可选：

- Google Ads/GA4 数据接入
- 头程物流成本导入
- VAT/关税规则表
- AI 问答助手
- 顾问工作台

暂不建议 MVP 做：

- 全自动调价
- 自动广告投放修改
- 自动发买家消息
- 自动税务申报
- 深度 ERP 替代能力

这些能力对权限、风控、客户信任要求更高，适合第二阶段再做。

## 6. AI 能力设计

### 6.1 AI 不直接替代接口

AI 层不负责直接“猜数据”，所有结论必须基于 Amazon API、广告 API、九米业务系统或客户上传数据。

推荐原则：

- 数据来自接口
- 计算来自规则和模型
- 解释来自 AI
- 关键动作由人确认

### 6.2 AI Agent 类型

| Agent | 作用 |
| --- | --- |
| 经营分析 Agent | 解释销售、利润、广告、库存变化 |
| 利润核算 Agent | 分析 SKU 是否赚钱，解释成本变化 |
| 补货 Agent | 预测断货，推荐备货和物流方案 |
| Listing Agent | 检查 Listing 质量并生成优化建议 |
| 关汇税 Agent | 整理税务资料，提示风险，生成顾问草案 |
| 顾问交付 Agent | 生成客户月报、会议纪要、服务工单 |

### 6.3 AI 输出规范

每条 AI 建议应包含：

- 结论
- 数据依据
- 影响金额或风险等级
- 建议动作
- 是否需要人工确认

示例：

```text
结论：英国站 SKU-A 本月广告后利润率从 18.4% 降至 7.2%。
依据：CPC 上升 31%，FBA 配送费上升 8%，售价未调整。
影响：按当前销量，预计下月少赚约 1,860 英镑。
建议：将售价从 19.99 调整到 21.49，或暂停 3 个低转化关键词。
人工确认：需要运营确认后执行。
```

## 7. 数据合规与风控

Amazon SP-API 对开发者权限、数据保护和受限数据有严格要求。九米在产品设计中必须提前纳入合规。

关键原则：

- 按最小权限申请 API 角色
- 明确客户授权范围
- 不长期保存不必要的买家个人信息
- 敏感数据加密存储
- 区分运营数据、财务数据、PII 数据
- 记录 API 调用日志和数据访问日志
- 客户可撤销授权
- 内部顾问按客户和角色分级访问

高风险能力：

- 买家姓名、地址、电话、邮箱等 PII
- 买家消息
- 财务结算数据
- 自动修改 Listing
- 自动调价
- 自动广告预算调整

建议九米第一阶段只做“分析和建议”，涉及自动修改 Amazon 账户的动作必须由客户或顾问二次确认。

## 8. 商业化服务包

### 8.1 基础版：经营数据看板

适合中小卖家。

包含：

- 店铺数据同步
- 销售/库存/广告基础看板
- 月度经营报告
- 基础异常提醒

收费方式：

- 按店铺/月收费
- 或作为 SPN 服务客户权益

### 8.2 专业版：利润与补货智能服务

适合已有稳定销售的卖家。

包含：

- SKU 级真实利润
- FBA 库存预测
- 补货建议
- 广告后利润分析
- 关税/VAT 成本测算

收费方式：

- SaaS 订阅 + 顾问服务费

### 8.3 增长版：Amazon + Google 流量增长

适合品牌卖家和增长型卖家。

包含：

- Amazon Ads 数据分析
- Google Ads 数据分析
- 站外引流 ROI
- ASIN 增长机会识别
- 投放策略月度复盘

收费方式：

- 服务费 + 广告管理费 + 增长绩效费

适合多店铺、多国家、多团队卖家。

- API 数据开放
- 定制报表
- 内部权限体系
- 财务税务对账
- 九米顾问团队深度服务

收费方式：

- 年费 + 实施费 + 定制开发费

## 10. 技术实现建议

### 10.1 后端

建议能力：

- OAuth 授权服务
- API 调度与限流
- 数据同步任务队列
- 报表异步下载
- 数据标准化
- 多租户权限
- 审计日志

### 10.2 数据层

建议建设：

- 原始数据层：保存 API 原始响应和报表文件
- 标准层：订单、SKU、ASIN、广告、库存、费用标准表
- 指标层：利润、库存天数、广告 ROI、客户健康分
- AI 语义层：可供 AI 查询和解释的数据集

### 10.3 前端

建议端口：

- 客户门户：给卖家看经营结果和服务建议
- 顾问工作台：给九米内部看客户风险和任务
- 管理后台：管理授权、客户、套餐、权限、接口状态

### 10.4 运维

必须具备：

- API 调用失败重试
- Amazon 接口限流处理
- 数据同步延迟监控
- 授权过期提醒
- 接口变更监控
- 报表生成失败告警

产品指标：

- 授权店铺数

客户价值指标：
